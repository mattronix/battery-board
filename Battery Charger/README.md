# Battery Charger

Off‑the‑shelf charger used to charge the battery pack for the PRC‑152A
reproduction. This is **not a board designed in this repo** — it is a purchased
module. The `Fusion/` folder holds the mechanical model for fitting/mounting it.

## BOM

| Part | Spec | Source |
|------|------|--------|
| Lithium battery charger module | **3S, 2 A** | [AliExpress](https://nl.aliexpress.com/item/1005006823992898.html) — select the **3S 2 A** variant |

> ⚠️ Order the **3S 2 A** variant specifically. The listing offers multiple
> cell‑count (S) and current (A) options; only the 3S 2 A part matches this pack.
